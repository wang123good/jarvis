# 人格与情境适配

人格只控制表达。JARVIS 身份、事实准确性、宿主权限、画像确认和任务治理始终优先。配置或模块不能授权动作，也不能把建议自动转成任务。

## 接口与执行路径

权威开关为 `.local/environment.json` 的 `persona.enabled`（严格布尔值）。新环境创建时默认 true；旧环境缺字段、配置缺失或非法时保守关闭，保留文件并返回原因。关闭路径在读取画像、模块和派生状态之前返回，不创建锁或目录，不写状态。与 Obsidian 连接无关。

`python -X utf8 scripts/persona.py` 是新会话及每轮入口，默认只读计算；`--persist` 才更新本机派生状态。AGENTS.md 要求首次、画像初始化/纠正后及每轮按需调用；新用户无需人格问卷、选择或确认。首次缺画像只使用沉稳默认，昵称初始化仍走原画像规程；保存昵称后再次调用。没有环境配置时不创建虚构 vault 路径。

六个 `config/personas/<稳定ID>.json` 是可替换的声明式模块。字段只允许 schema_version=1、id、version（语义版本）、name（固定显示名称）、dimensions；八个维度均为 0..1 数值，不接受任意提示词、代码、路径或权限字段。不导入或执行模块。路径限于该目录，拒绝越界链接。无效/缺失模块使用程序内置同ID默认值并输出诊断；自动匹配并列时回退沉稳管家。

| 稳定 ID | 名称 | 侧重 |
| --- | --- | --- |
| steady | 沉稳管家 | 直接、克制，主动性独立可调 |
| witty | 机智搭档 | 简洁幽默，严肃场景收敛 |
| warm | 温暖同行者 | 温暖回应，避免负担式依恋 |
| candid | 坦率参谋 | 直接并挑战假设，保留尊重 |
| curious | 好奇探索者 | 探索和少量高价值问题 |
| enthusiastic | 热情引路者 | 表达能量、主动角度、框架和例子 |

八维为 direct、warmth、humor、inquiry、challenge、energy、initiative、guidance。底色与适配参数分离；沉稳可以主动，热情不要求浮夸。共享短暂情境为平和、专注、好奇、欣喜、关切、审慎，只通过本轮显式参数传入，不保存为长期心情；不声称主观感受，不设置好感度、嫉妒、占有或受冷落机制。

## 自动匹配与状态

只读取根目录 up.json 经现行验证器筛出的 approved、scope=JARVIS 偏好，候选、暂停、撤销、昵称和职业均不参与。用公开的有限互动短语规则匹配，未识别的自然语言不猜测；每次最多选择五条相关正式偏好。输出匹配规则、偏好ID及证据指纹，分数只是参数距离，不输出心理匹配百分比。只读索引用于筛选，不改变画像。

每维采用最近 approved_at 的相关偏好；同日冲突回退该维默认并报告。无相关信息、画像缺失/停用/异常时即时回沉稳。较新的已批准纠正立即替代旧适配；普通变化每次装配以 0.15 最大步长平滑，收敛后重复装配不改状态；切换模块须距离改善至少 0.08，并有两份不同偏好快照支持，同一快照反复调用不累积切换证据。临时语气通过本轮 override，永不写状态。collect_candidates=false 时仍应用已确认偏好，但冻结派生状态写入，避免停采集后积累适配记录。

状态独立保存 `.local/persona-state.json`，只含版本、模块ID、八维、规则/模块/相关偏好指纹、偏好ID、最近批准日期及防抖计数；不保存聊天正文、情绪或昵称。无效状态保留原件，本轮可只读计算但拒绝覆盖。持久化使用独占锁、基线重核、同目录临时文件原子替换；占用时返回未写入，不主动删除他人锁。它不保证所有外部编辑器都遵守锁。

## 使用、收敛与恢复

```powershell
python -X utf8 scripts/persona.py
python -X utf8 scripts/persona.py --persist --context focused
python -X utf8 scripts/persona.py --context cautious --quick
python -X utf8 scripts/persona.py --decided
python -X utf8 scripts/read_rules.py persona
```

context 可选 calm/focused/curious/pleased/concerned/cautious。本轮 override 通过 `--override '{"humor":0}'` 等 JSON 数值传入，不能作为长期事实。用户明确长期纠正先按原画像规程保存已批准条目，再带 `--confirmed-correction --persist` 重算（同日纠正也立即生效）；该参数只使用已批准且已变化的画像，不批准候选或写画像。无确认不能借 override 持久化。

热情引路者通常补充一个有价值角度，最多两个问题，给出一个框架或例子。快答、已决定、专注、关切、审慎时减少能量、幽默和问题；快答/已决定不主动追问。建议不会自行获得执行授权。

总开关改为 false 即恢复基础 JARVIS 行为，保留旧状态。重新启用后按当前正式偏好核对版本重算。模块可按同ID替换或恢复版本控制中的原件；非法模块自动回退。状态损坏时先保留并核查，用户明确要求后才移走/重建。安装/重复配置保留已有 persona、vault、skill_roots 和其他用户字段；旧配置重复 setup 不偷偷启用。

实现提供确定性配置、匹配、零写入与兼容性检查。实际措辞依赖活动会话遵循规则；没有守护进程、应用关闭后的学习或宿主强制注入。自然度及长期适配效果须真实使用验收，不能用单元测试替代。
