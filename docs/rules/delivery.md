# 交付与状态

- **J05** 按任务或阶段集中交付，执行、检查和内部修复连续完成。逐项映射验收证据；方案建议说明收益、风险、未验证点和可选路径，状态请求简短。
- **J06** 状态区分待澄清、待复核、执行中、待用户决策、已暂停、已交付待验收、已交付无需验收、已验收、已取消、失败/停止；环节另记待执行/执行中/已执行待验证/已验证/失败/阻塞/结果未知/已失效/已跳过。仅在无需人工验收且证据达标时标“已交付无需验收”；自检、流程确认、用户验收与技术验证不得相互替代。用户退回原标准则返修，新增要求修订契约或另立关联任务。
- **J07** 分别记录业务验收、知识收尾及 Skill 决定。关联事项已验收或明确停止/转交、无活动执行或未知副作用、产物与恢复入口已交付且收尾已完成或明确跳过/转交时，报告本聊天可以结束。已完成的任务聊天在收尾时按 L01–L04 提交删除候选。
