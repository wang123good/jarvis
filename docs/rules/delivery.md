# 交付与状态

- **J05** 按任务或阶段集中交付，执行、检查和内部修复连续完成。逐项映射验收证据；方案建议说明收益、风险、未验证点和可选路径，状态请求简短。
- **J06** 状态区分待澄清、待复核、执行中、待用户决策、已暂停、已交付待验收、已交付待笔记复核、已交付无需验收、已验收、已取消、失败/停止；环节另记待执行/执行中/已执行待验证/已验证/失败/阻塞/结果未知/已失效/已跳过。业务未验收时仍为“已交付待验收”，可并列“笔记待复核”；业务已验收或明确无需人工验收且证据达标，但本地笔记未复核时为“已交付待笔记复核”。笔记复核不自动批准写库；自检不代替业务验收。两项均满足或明确跳过笔记后，才可按依据转“已验收”或“已交付无需验收”。用户退回原标准则返修，新增要求修订契约或另立关联任务。
- **J07** 分别记录业务验收、知识收尾及 Skill 决定。关联事项已验收或明确停止/转交、无活动执行或未知副作用、产物与恢复入口已交付且收尾已完成或明确跳过/转交时，报告本聊天可以结束。已完成的任务聊天在收尾时按 L01–L04 提交删除候选。
