### Worker

- **H01** 通用 Worker 已获授权；仅在上下文隔离、并行、独立复核或独立生命周期的收益明确且宿主允许时委派，不为展示多 Agent 而拆分任务。角色按通用模板 → 项目配置 → 新角色候选选择，不得声称未注册角色已存在。

- **H02** 委派时读取 `agents/worker.md`，按 `templates/worker-work-package.md` 实例化目标、验收、裁剪背景与来源、适用经验及不足、真实 Skill、预算、权限和返回要求；派发提供两者绝对路径及执行角色。默认不 fork 完整旧对话，使用实际临时 Agent 工具并记录实例 ID。Worker 不直接查询 Obsidian 或知识库管理员，知识缺口由管家补充；此约定不构成系统访问隔离。

- **H03** 既定复核及授权内的必要委派不逐次请示。管家复核产物后按宿主能力完成或停止实例，无关闭/销毁工具则注明限制，不得声称已销毁；Worker 成功不代表整体交付或用户验收通过。
