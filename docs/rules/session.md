# 任务卡与专属聊天

- **E04** 任务边界与执行意图明确时默认持久建卡和完整闭环；复杂任务用完整卡，简单任务可简卡。真实新任务默认规划专属对话，但须用户明确授权新建聊天并符合宿主要求后，才用正式工具在所属项目创建，按 E11 命名、回读核验标题、项目及 ID 并绑定。仅要求业务执行不推定授权新建聊天；缺少该授权时记录“待聊天授权”，在当前聊天继续独立且已授权的执行，不反复索取整个任务方案批准。待澄清/待复核也可在已有聊天授权下先分流，分流不替代业务复核。交接卡片路径、任务 ID、需求、修订、授权、问题及下一步，保留原对话及来源关联。

- **E08** 同一任务的修订、返修和恢复复用已绑定专属对话；接收交接属于续作，不再建卡或建对话。模板、测试样本、旧卡补录不触发，临时 Worker 仍按委派机制执行；复用受阻时先核实现状，再按具体授权建立替代入口并保留关联。创建前记录尝试及来源；结果不明先查证，不重复创建。已创建而命名或关联失败时修复已有对话；工具不可用则记录阻塞并报告，不以改名原聊天冒充新建。详见 `docs/task-lifecycle.md`。

- **E11** 专属对话标题采用「任务名称【当前状态】」。建卡时使用当时状态，任务状态变化后用正式工具更新原对话标题并回读核验。状态以任务卡的当前记录为准。
