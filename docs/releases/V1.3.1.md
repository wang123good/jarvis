# V1.3.1 · 2026-11-25

修复知识库目标路径的持久选择，减少重复询问，并防止多库环境下写入错误位置。

- `JARVIS_VAULT_ROOT` 优先选择当前进程值，Windows 下未设置进程值时读取用户持久值；非法路径或连接器冲突直接拒绝。
- `setup_environment.py --vault <已有目录>` 统一完成用户变量持久化、本机配置和检索指针生成，兼容 `--connector-vault`。冲突的进程覆盖在写入前拦截，配置失败恢复原值和本机文件。
- 旧本机配置仍可兼容读取；迁移时移除重复库路径，保留人格、Skill 和自定义设置。切库不搬迁笔记。
- 写入前重检环境漂移，安装检查纳入持久化脚本，测试隔离真实知识库环境。

验证：unittest 全量 104 项通过；候选分发包首次配置及后续解析通过，缺少关键脚本的包被安装检查拒绝；实际本机环境和项目检索检查通过。候选包初始化使用模拟 Windows 用户注册表，未覆盖全新系统账户、Obsidian 图形界面或外部全局 Skill 集成。

本机配置、个人画像、知识库笔记及运行证据不包含在发布中。本次同步代码和版本说明，不另建 GitHub Release。
