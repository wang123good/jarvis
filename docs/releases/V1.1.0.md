# V1.1.0 — 2026-11-20

本次较重大重构按用户明确指定的 V1.1.0 发布。

- 原内层 `jarvis/` 按职责拆为 `agents/`、`config/`、`templates/`、`scripts/`、`tests/` 和 `docs/`，同步入口及路径引用。
- 本地任务、请求和运行记录统一放入 `.local/`，排除个人画像、业务附件、缓存与历史打包文件。

- 精简入口、操作说明、管理员定义和工作包重复内容，保留权限、验证、停止及活动会话清理保护要求。
- 知识库采用草稿／工作记录／wiki 布局，分发九份模板及保护既有文件的初始化程序。
