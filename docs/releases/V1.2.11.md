# V1.2.11 · 2026-11-24

本次常规修复解决 JARVIS 首次接入 Obsidian vault 时缺少本机路径配置、以及已安装检索 Skill 无法读取项目环境文件的问题。

- 新增 `scripts/setup_environment.py`，由 Obsidian 实际报告的 vault 路径原子创建或校验 `.local/environment.json`，并生成本地检索配置。
- 已有不同 vault 时默认拒绝覆盖，只有显式使用 `--replace` 才更新；失败时恢复原环境文件，且不修改 `up.json`。
- `scripts/resolve_environment.py` 在配置缺失时返回 `configuration_required` 和可直接执行的下一步，不再只给出模糊 vault 错误。
- 明确 vault 绝对路径只属于机器环境配置，不写入用户画像、共享 `.codex` 配置或 Git 跟踪文件。
- 更新首次接入流程、画像、知识和操作文档，并将新脚本纳入安装资源检查。

49 项单元测试通过，完整安装检查通过。当前机器已用真实知识库验证配置解析、运行时指针、Obsidian 检索 Skill 兼容和项目限定检索；本机路径、个人画像和知识库正文未上传。
