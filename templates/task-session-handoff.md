# 已有任务交接：TASK-NAME

这是已有任务的专属对话接收，不是新任务创建请求。不得再次建卡或创建对话，不自动继承未列出的旧任务。

- task_id：填写稳定任务 ID。
- 任务卡绝对路径：填写现有 contract.md 路径。
- contract_revision / plan_revision：填写当前修订。
- source_thread_id / project_id：填写正式来源对话与项目 ID。
- 目标对话名称：使用任务名称；不以标题代表真实状态。
- 原始需求及预期结果：保留用户关键要求，区分事实、假设和待确认项。
- 当前状态与授权：分别列出已批准、待批准和禁止推进的范围；创建对话不等于业务执行批准。
- 必要输入与来源：仅列本任务所需路径、版本或定位；不粘贴整段旧对话或跨项目敏感内容。
- 最近有效检查点：已验证结果、活动执行、未知副作用、剩余预算及失败记录；不可观测项写未知。
- 当前待确认问题：集中列出真正影响后续的缺口。
- 下一步：首次只读核对规则、任务卡及必要交接材料，简短确认任务 ID、目标和待确认项，等待用户继续；不启动未复核的业务执行。
- 接收约束：接收属于续作，禁止递归建卡/建对话；绑定未完成或不一致时报告，不争抢写卡或执行。不因任务转移重置预算、接受旧草稿为事实或自动写知识库。

由来源会话保存创建回执并完成唯一专属对话绑定；接收方首轮只读。来源会话核对接收结果后停止推进该任务业务。工具回读与侧边栏视觉检查分别记录，原对话保留。
